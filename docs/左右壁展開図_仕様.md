# 展開図 仕上げ仕様（全周・左壁・右壁）

**作成日：** 2026-06-24
**対象：** トンネル/暗渠の点検用展開図（全周＝魚の開き／左壁のみ／右壁のみ）
**位置づけ：** 既存 F04 `generate_tunnel_development`（全周）を「つぶさず・実長・きれい・無駄なカット無し」に整え、さらに左壁のみ／右壁のみを個別出力できるよう拡張する。

> 展開のイメージ（最重要）
> - 基本は「**魚の開き**」（円筒内面を切り開いて平面に展開）。
> - さらに「**ローラーで均して平らに伸ばす**」イメージ。曲面（断面アーチ）も曲線（平面の曲がり）も、
>   ローラーで押し延ばすように**実面長・実延長のまま平らに伸ばす**。**縮めない・潰さない**。
>   - 横方向：トンネルが曲がっていても、中心線に沿って**ローラーを転がした実延長（弧長）**で伸ばす（弦長に縮めない）。
>   - 縦方向：断面のアーチも**ローラーで伸ばした実アーク長**で平らにする（投影でつぶさない）。
>
> 共通方針（全図面に適用）
> - **つぶさず平ら**：横＝中心線沿いの実延長（弧長）、縦＝断面/壁面の実アーク長。投影で縮めない。
> - **実長保持**：曲がり（平面）・勾配（縦断）・アーチ湾曲（断面）すべて弧長で展開し実寸を保つ。
> - **きれいな仕上がり**：§11。
> - **不必要なカットをしない**：§12。坑口の大断面・延長端を切り捨てない。

---

## 1. 目的
トンネル点検（クラック調査等）で、**左壁だけ・右壁だけ**を1枚の平らな展開図にしたい。
- **長さは実寸**：トンネルが曲がっていても、中心線に沿った**実延長**を横軸にして真っ直ぐに伸ばす（弦長でなく弧長）。
- **曲がりをつぶさず平らにならす**：壁面アーチの湾曲も、断面の**弧長**で展開して実面長を保つ（投影でつぶさない）。

## 2. 基本コンセプト（既存ロジックの再利用）
既存 `generate_tunnel_development` は既に下記を満たしている：
- 横軸 = `_pca_alignment` の測点 `s`（中心線アライメント沿いの弧長＝**実延長**。横断曲がり・縦断勾配を断面中心で吸収）
- 縦軸 = 断面円周の展開アーク長 `dev*rad`（**曲面を平らに展開**）

→ 本機能は、この点群を**左右に分割**し、各側だけを展開して出力する。

## 3. 左右の分け方（既定と選択肢）
断面中心（測点ごとの `thc`）の**鉛直面**で左右に二分する。
```
        天端(crown)
          /│\
   左壁  / │ \  右壁     ← 既定: 中心鉛直面(dth=0)で左右分割
        /  │  \
  ─────左─┼─右─────
       インバート(invert)
   dth<0 → 左壁 / dth>=0 → 右壁   （dth = th - thc）
```
- `wall_split`（設定）★**採用＝`"centerline"`（2026-06-24 確定）**
  - `"centerline"`（**確定・既定**）：断面中心の鉛直面で二分。左壁＝中心面より左（底〜天端まで）／右壁＝中心面より右。2枚で全体をカバー。
  - `"springline"`（オプション）：起拱線で側壁のみを切り出し、天端・インバートを除外
- `flip_lr`：進行方向の取り方で左右が反転する場合に左右を入れ替える

## 4. 展開座標の定義（実長保証）
各点 P について：
- **u（横＝展開延長）** = `s`（中心線弧長）。曲線トンネルでも実長で straighten。
- **v（縦＝壁面展開高）** = 基準線(datum)から壁面に沿った**弧長**。
  - `wall_datum`（設定）：`"invert"`（既定・底基準）/ `"springline"`（起拱線基準）/ `"floor"`
  - 左壁：基準から**左側のアーチに沿って**天端方向へ弧長を積算
  - 右壁：基準から**右側のアーチに沿って**天端方向へ弧長を積算
  - 実半径で展開（`dev*rad`）し**引き伸ばさない**＝断面サイズの変化はそのまま出す（既存方針踏襲）

これにより、横も縦も「曲がりをつぶさず・実長で平ら」になる。

## 5. 出力
| 図面 | 内容 |
|---|---|
| 左壁展開図 DXF/PNG | 横=展開延長(測点+追加距離) / 縦=壁面展開高 / レイヤー `WALL_L` |
| 右壁展開図 DXF/PNG | 同上 / レイヤー `WALL_R` |

- 様式は既存 `export_developed_elevation_dxf` に準拠：実寸外枠・1mグリッド・横/縦寸法線・**表題欄**（図面名「左壁展開図」「右壁展開図」/工事名/縮尺/作成者/日付）。
- `embed_raster` でスキャン画像を実寸埋め込み（AutoCAD でなぞれる）。
- 横軸 `station_pitch`、縦軸 `elevation_axis_pitch` は既存設定を流用。

## 6. 関数 I/F（実装案）
```python
def generate_tunnel_wall_development(
        pts, side="left",          # "left" / "right"
        cfg=None, resolution=None,
        wall_split="centerline",   # "centerline" / "springline"
        wall_datum="invert",       # "invert" / "springline" / "floor"
        n_station_bins=300,
        flip_lr=False) -> (img, meta)
```
- 内部は `generate_tunnel_development` の測点・中心線・展開処理を再利用し、`dth` の符号（と `wall_split`）で対象側のみ抽出 → datum 基準で v を再ゼロ → ラスタ化。
- GUI（`gui_app.py`）：トンネル選択時に「展開図（全周/左壁/右壁）」のラジオを追加。左壁・右壁は1回の実行で2枚同時出力も可。

## 7. 設定追加（config.json）
| キー | 既定 | 説明 |
|---|---|---|
| `wall_split` | `"centerline"` | 左右の分割基準 |
| `wall_datum` | `"invert"` | 縦軸の基準線 |
| `wall_dev_resolution` | `tunnel_resolution` 準拠 | 壁展開の解像度(m/px) |
| `flip_lr` | `false` | 左右反転 |

## 8. 前提・制約
- **入力点群がクリーンであること**（SLAMドリフト品はNG）。RS10は `rs10_quality_check.py` の判定で `clean` のもののみ推奨。
- アライメントはXY主成分（直線近似）。大きく蛇行する線形は中心線ファイル（`get_centerline`）併用が望ましい（既存 §9 と同じ制約）。
- 左右判定は進行方向に依存 → `flip_lr` で補正。
- 天端・インバートの取り扱い（左右どちらに含めるか）は `wall_split` で選択。

## 9. 受け入れ確認（ダミーデータ）
- `test_tunnel.las`（曲がり・勾配付き）で全周・左壁・右壁を出力し、
  - 横軸長がトンネル実延長と一致（弦長でない）
  - 縦軸が壁面/円周アーチの実面長（投影でつぶれていない）
  - クラック模擬が歪まず読める
  - 坑口の大断面・延長端が切れていない（§12）
  を確認する。

## 10. 全周展開図（魚の開き）も「つぶさず平ら・実長」に
既存 `generate_tunnel_development` は概ね満たすが、本仕様で明文化・徹底する：
- 横軸 = 中心線沿いの測点 `s`（**実延長**。弦長やXY投影で縮めない）。
- 縦軸 = 断面円周の**実アーク長** `dev*rad`（各点の実半径で展開、引き伸ばし・圧縮なし）。
- 縦の上限は `arc.max()`（**坑口など大断面も全高表示**、頭打ちでカットしない）。
- seam（切り口）位置のみ選択可（crown/invert）。切り口以外で円周を分断しない。
- 縦断勾配・平面曲がりは測点ごとの断面中心で吸収し、形状をつぶさない。

## 11. 仕上がり品質（見た目をきれいに）
点検図として読みやすく、AutoCADでなぞりやすい見た目に整える。
- **解像度**：既定解像度を見直し、必要なら `max_pix` を上げる/タイル分割で**無理な縮小ぼけを避ける**（メモリ上限は維持しつつ品質優先）。
- **隙間補間の改善**：`_fill_gaps` を最近傍色だけでなく、小穴は近傍メディアン/モルフォロジ閉処理で自然に充填。点密度ムラの縞を低減。
- **アンチエイリアス**：点のラスタ化で1px欠けを防ぐ（近傍加算 or 微小カーネル）。
- **色調整**：強度/カラーの自動レベル補正（暗い点群を見やすく）。背景色 `bg` と壁面のコントラストを確保。
- **外れ値（ノイズ）除去**：宙に浮いた孤立点・飛び点のみ統計的に除去（§12の「構造のカット」とは区別。**実構造は消さない**）。
- **端の処理**：背景の縁を均し、表題欄・グリッド・寸法線を整然と配置。
- これらは config で ON/OFF・強度調整可能にする（既定は控えめ）。

## 12. カット方針（不必要なカットをしない）
- **延長方向**：測点範囲を端で切らない。坑口～坑口の全長を出す。
- **断面方向**：大断面（坑口拡幅部・退避坑など）も**全高・全幅**を表示。`max_pix` 超過時も**クロップせず**解像度調整で対応。
- **クリップ**：`px/py` のクリップは画像内に収める保険のみで、データ範囲は `arc.max()`/`s.max()` を基準に画像側を合わせる（点を端に潰さない）。
- 許容する除去は**明確なノイズ（孤立点・飛び点）のみ**。壁・天端・インバート・坑口など**構造点は一切カットしない**。
- ノイズ除去は既定弱め＋ログ出力（何点除去したか）で、過剰除去を防ぐ。

## 13. 実装影響（まとめ）
- `generate_tunnel_development`：§10/§11/§12 を反映（縮小ぼけ回避・補間改善・ノイズ除去オプション・端カット禁止）。
- `generate_tunnel_wall_development`（新規）：§3〜§6。全周ロジックを左右分割で再利用。
- 共通の仕上げ処理（補間・AA・レベル補正・ノイズ除去）は**ヘルパ関数に共通化**して全展開図で使う。
- config 追加：§7 に加え `finish_denoise`(bool/強度)、`finish_levels`(bool)、`fill_method`、`max_pix` 見直し。
