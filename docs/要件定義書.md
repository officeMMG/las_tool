**作成日：** 2026年6月20日

**対象機器：** CHCNav RS10 / Scaniverse（iPhone LiDAR）
**作成者：** 西田岳司（岳_デザイン）

---

## 1. 背景・目的

CHCNav RS10（SLAM LiDAR）およびScaniverse（iPhone LiDAR）で取得した点群データを使い、擁壁・トンネルの点検業務（クラック調査等）に活用できる**展開図・平面図・縦断図**をDXF形式で出力するツールを開発する。

現状の課題：
- CoPre処理後のカラー点群画像が汚く、仕上げ編集が大変
- 展開図・平面図・縦断図の作成に専用ソフトが必要
- AutoCAD / Bluetrend への橋渡しとなる下書きDXFを自動生成したい

## 3. 対応データ形式

| 機器 | 形式 | 備考 |
|------|------|------|
| CHCNav RS10 | LAS + IMGフォルダ（JPG）+ 軌跡データ | CoPre処理済みデータ |
| Scaniverse | LAS（PLY変換も可） | 写真テクスチャなし |
| 中心線座標 | CSV（x,y,z）/ TXT（スペース区切り） | 縦断図のセンターライン用（任意） |

LAS読み込みは `laspy` を使用し、XYZ・RGBカラー・強度（intensity）を取得する。カラー・強度が無いデータはグレー値で補完する。

## 4. 機能要件

### 4.1 フェーズ1（基本機能）※実装済み

| No | 機能 | 内容 | 実装状況 |
|----|------|------|---------|
| F01 | LASファイル読み込み | laspy使用・点数/XYZ範囲・カラー有無を取得 | ✅ `load_las` |
| F02 | 壁面切り出し | X軸 or Y軸方向で位置・厚みを指定して抽出 | ✅ `extract_wall_points` |
| F03 | 擁壁展開図生成 | 測量様式（測点+追加距離/実標高軸/天端・地盤線/表題欄/縮尺/画像埋込） | ✅ `generate_elevation_wall` + `export_developed_elevation_dxf` |
| F04 | 展開図生成（トンネル/魚の開き・アライメント追従） | 中心線をXY主成分で自動判定し円周展開。縦断勾配・斜め・曲がり対応。横=展開延長/縦=円周。展開基準を天井基準/地面基準から選択可 | ✅ `generate_tunnel_development`（軸並行版 `generate_elevation_tunnel` も残置） |
| F05 | 平面図生成 | 真上投影・最上面の色を採用・最大6000px制限 | ✅ `generate_plan_view` |
| F06 | センターライン取得 | 座標ファイル→展開図センター→点群自動推定の優先順位 | ✅ `get_centerline` ほか |
| F07 | 縦断図生成 | 天端・左壁・右壁・インバート・中心を展開延長で抽出（アライメント対応で壁高差・勾配を表現） | ✅ `generate_longitudinal` / `generate_profile` |
| F07b | アライメント自動整列 | 中心線(XY主成分)に沿わせて全図面を生成（斜め・任意方向対応） | ✅ `reorient_by_alignment` |
| F08 | 横断図生成（トンネル/擁壁） | 任意測点でスライス・トンネルは閉リング/擁壁はプロファイル・複数測点対応 | ✅ `generate_cross_section(s)` |
| F09 | DXF出力（展開図） | 実寸外枠・1mグリッド・横/縦寸法線・タイトル | ✅ `export_elevation_dxf` |
| F10 | DXF出力（平面図） | 実寸外枠・5mグリッド・座標値ラベル・点群間引きプロット | ✅ `export_plan_dxf` |
| F11 | DXF出力（縦断図） | レイヤー分け・グリッド・凡例・縦スケール注記 | ✅ `export_profile_dxf` |
| F12 | DXF出力（横断図） | 断面輪郭・外枠・グリッド・測点ラベル・単一/複数並べ出力 | ✅ `export_cross_section(s)_dxf` |
| F13 | ダミーデータ生成 | 擁壁/トンネルのテスト用LAS（クラック模擬含む）を生成 | ✅ `generate_dummy_*` |
| F14 | 設定カスタマイズ | 解像度・グリッド・色・縦スケール等をJSONで変更 | ✅ `config.py` / `config.json` |
| F15 | GUIアプリ | tkinterデスクトップUI（入力選択・図面選択・パラメータ・実行・プレビュー・設定保存/読込） | ✅ `gui_app.py` |

#### F14 設定カスタマイズの詳細
- すべてのパラメータを `config.py` の `Config` データクラスに集約
- `config.json` を編集すればコードを触らず調整可能（`python config.py` でテンプレート生成）
- 各処理関数は `cfg=` を任意で受け取り、未指定なら `config.json`（無ければ組み込み既定値）を自動使用（後方互換）
- 変更可能：解像度（展開図/トンネル/平面図）、最大ピクセル、壁面切り出し厚み、背景色、各グリッドピッチ、縦断図のスライス数/スライス幅/縦スケール/延長軸、横断図のスライス厚/角度分割/高さビン数/測点ピッチ/グリッド/断面線色、平面図プロット点数上限、DXFバージョン、寸法スタイル、ラスタ画像のDXF埋め込みON/OFF（`embed_raster`）、展開図様式（測点ピッチ/標高軸ピッチ/天端・地盤線抽出/表題欄/縮尺/工事名/作成者）、各種色（外枠/グリッド/タイトル/点群/縦断図レイヤー/天端線/地盤線）

#### F06 センターライン取得の詳細（優先順位）
1. **中心線座標ファイル**（CSV/TXT）が指定されていればそれを採用
2. 展開図メタデータ（トンネル）の arc 中央をセンターとして生成
3. 点群をZ方向にスライスし各スライスのXY重心を繋いで自動推定

#### F07 縦断図生成の詳細（2モード）
- `tunnel_axis="z"`：Z軸がトンネル延長方向（RS10/Scaniverse標準）。横断面=XY平面でスライス
- `tunnel_axis="xy"`：XY平面が延長方向。センターラインに追従して法線方向で左右を判定

#### F08 横断図生成の詳細
- 指定測点で延長軸に直交する薄いスライスを切り出し、断面形状を抽出
- **トンネル**：断面重心まわりの角度ビンごとに半径中央値をとり、閉じたリング輪郭を生成
- **擁壁**：高さ方向ビンごとに横位置中央値をとり、壁面プロファイル（開輪郭）を生成
- 単一測点（`generate_cross_section`）／一定ピッチの複数測点（`generate_cross_sections`）に対応
- 複数断面は1枚のDXFに並べて出力可能（`export_cross_sections_dxf`）

#### F15 GUIアプリの詳細
- `python gui_app.py` で起動するtkinterデスクトップアプリ
- LAS選択・ダミーデータ生成・対象種別（擁壁/トンネル/水路）・出力図面の選択（展開図/平面図/縦断図/横断図）
- 主要パラメータ入力（config.json と連動）・出力先指定・実行・ログ
- プレビューは拡大縮小（ホイール/ボタン）・移動（ドラッグ）・原寸/高さ合わせ/全体・回転（⟲⟳90°/角度指定）に対応
- 横長図面は既定で高さ合わせ表示し、画面外は横スクロールバー（Shift+ホイール可）で送る
- 展開図/平面図はスキャン画像、縦断図/横断図は線画DXFを画像化（matplotlib・日本語フォント対応）してプレビュー表示
- 工事名・縮尺（1:50〜1:500）を入力でき、展開図の表題欄/図面に反映
- アライメント自動整列で全図面を中心線に沿わせる
- ワークフロー：**実行（作成・確認）→ 保存（外部出力）** の2段
  - 「実行」：現場別の作業フォルダ `works/<現場名>/` に図面を作成・プレビュー（外部保存しない）
  - 「保存…」：作成済みが問題なければ押下。ダイアログで**保存先選択＋図面の最終選択＋出力方法**（個別／1枚にまとめる／ZIP）を指定して外部出力
- **現場メモリ**：現場名ごとに作成図面を記憶（`works/projects.json`）。現場名プルダウンで過去現場を選び「履歴」で作成図面を確認
- 設定の保存/読込（config.json）。重い処理は別スレッドで実行しUIは固まらない

## 6. 出力ファイル仕様

### 6.1 擁壁展開図DXF（測量様式）
- 横軸：測点(No.)＋追加距離（展開長）。測点ピッチは `station_pitch`
- 縦軸：実標高(m)。目盛ピッチは `elevation_axis_pitch`
- 天端線・地盤線を点群画像から自動抽出（`extract_outline`）
- スキャン画像を実寸で埋め込み（`embed_raster`、AutoCADでなぞれる）
- 表題欄（工事名/図面名/縮尺/作成者/作成日）・縮尺表記
- ※トンネル展開図は従来様式（円筒展開＋外枠/グリッド/寸法/画像埋込）

### 6.2 平面図DXF
- スキャン画像を実寸で埋め込み（`embed_raster`）。埋め込み時は点群プロットを省略
- 外枠：実寸（メートル単位）
- グリッド：5mピッチ（DASHED）
- 座標値ラベル（x_min/y_min基準の実座標）
- 画像を埋め込まない場合は点群を間引いてポイント描画（最大約5万点）

### 6.3 縦断図DXF（新規）
- レイヤー構成：
  - `CROWN`（天端／赤）
  - `LEFT`（左壁／青）
  - `RIGHT`（右壁／緑）
  - `FLOOR`（地面／黄）
  - `CENTER`（センター／白）
  - `GRID`（グリッド・寸法／灰）
  - `TITLE`（タイトル・凡例／緑）
- グリッド：横5m or 10mピッチ（延長で自動切替）、縦1mピッチ
- 凡例（各ライン色見本＋ラベル）・縦スケール注記（×n / 実寸）

### 6.4 横断図DXF（新規）
- レイヤー構成：`SECTION`（断面輪郭線）／`GRID`（外枠・グリッド）／`TITLE`（測点ラベル）
- トンネル：閉じたリング輪郭／擁壁：壁面プロファイル（開輪郭）
- 外枠・グリッド（既定1mピッチ）・測点ラベル（STA）
- 単一断面、または複数断面を一定間隔で並べて1枚出力

### 6.5 アライメント整列
- 全図面（展開図・平面図・縦断図・横断図）を中心線（XY主成分）に整列して生成
- 斜め・任意方向の構造物でも延長方向を横軸にした正しい図面になる
- 壁高が異なる箇所は、展開図（実標高）と縦断図（天端/左壁/右壁/インバートのライン）で高さ差として表現
- ※「一連図」は展開図と同等になったため廃止

## 9. 制約・除外事項

- 成果図面としての提出にはAutoCAD / Bluetrend での人的確認・仕上げが必要
- Bluetrend固有フォーマットへの直接出力は対象外（DXF経由で対応）
- リアルタイム処理は対象外
- Scaniverseデータは写真テクスチャ非対応（点群カラーのみ）
- 縦断図の左右壁判定は簡易ロジック（重心 or センターライン法線基準）であり、複雑形状では人的補正が必要
- 横断図の輪郭は角度ビン/高さビンの中央値による近似であり、複雑形状では人的補正が必要
- トンネル展開のアライメントはXY主成分（直線）近似。大きく蛇行する線形では区間分割や中心線ファイルの利用が望ましい
- DXFに埋め込むスキャン画像はPNGを相対パスで参照するため、DXFと同フォルダにPNG（`_プレビュー.png`）を保持する必要がある
